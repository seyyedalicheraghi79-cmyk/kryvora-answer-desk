Kryvora Answer Desk

برای پاسخ‌گویی هوشمند، کلید OpenAI API لازم است. کلید در حافظهٔ محلی مرورگر ذخیره می‌شود و برای درخواست‌ها به api.openai.com فرستاده می‌شود.

صفحه کوییز را باز کن، پنل «جواب سریع Kryvora» را بزن و سپس «خواندن صفحه» و «پیدا کردن جواب» را انتخاب کن.

هزینه API جدا از اشتراک ChatGPT است.
