Kryvora Answer Desk

این نسخه از Gemini API گوگل استفاده می‌کند. برای شروع، از Google AI Studio یک کلید API بساز و اینجا ذخیره کن. استفاده در محدوده سهمیه رایگان ممکن است؛ محدودیت‌ها به مدل، منطقه و سیاست‌های جاری گوگل بستگی دارد.

صفحه کوییز را باز کن، پنل «جواب سریع Kryvora» را باز کن و سؤال و گزینه‌ها را وارد کن. افزونه گزینه را خودکار انتخاب یا ارسال نمی‌کند.

کلید در حافظه محلی مرورگر ذخیره می‌شود و برای درخواست‌ها به Google Gemini API ارسال می‌شود. از کلید خود محافظت کن.
